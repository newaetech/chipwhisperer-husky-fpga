************
Introduction
************

Here you will find all the documentation for the FPGA design files of
ChipWhisperer Husky (and Husky Plus).

The FPGA source code is in the 
`chipwhisperer-husky-fpga repository <https://github.com/newaetech/chipwhisperer-husky-fpga>`_.

It's starting out lean, but we will be adding more content over time, with a
particular focus on making it easier to contribute or re-use. If there's a
specific part of the Husky FPGA code that you'd like to contribute to or borrow
from, let us know and we'll try to prioritize writing up that particular
section!

If you have any unanswered questions, the best way to get answers is to ask on
our `forum <https://forum.newae.com>`_.

GitHub issues can be filed `here <https://github.com/newaetech/chipwhisperer-husky-fpga/issues>`_.
